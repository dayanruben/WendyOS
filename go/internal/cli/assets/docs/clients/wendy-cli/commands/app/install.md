# `wendy app install`

> **This spelling does not exist.** The AppStore install command is
> `wendy device apps install <app-id>`. Top-level `wendy install` is the
> WendyOS image installer, and there is no `wendy app` command group.
>
> See [`wendy device apps install`](../device/apps/install.md) for the flags,
> the AppStore resolution API, and examples.
